# Prowlarr

Central indexer manager for the *arr suite. You add a torrent tracker
or Usenet indexer to Prowlarr once, and it syncs that indexer out to
Radarr and Sonarr automatically — instead of configuring the same
indexer in each app.

Runs through the WireGuard VPN netns so indexer traffic exits via the
VPN provider.
