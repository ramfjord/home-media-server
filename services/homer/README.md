# Homer

A static dashboard that lists every service in the stack with its URL
and a health indicator. Lives at `/` so it's the first thing you see
when you hit the box in a browser — the human-facing entry point to
the stack.

`config.yml.elp` builds the service cards from the manifest, so a new
service shows up on the dashboard automatically.
